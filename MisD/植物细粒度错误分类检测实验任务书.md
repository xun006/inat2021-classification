# 植物细粒度错误分类检测实验任务书

## 0. 文档定位与实验边界

本任务书用于指导后续代码实现、训练、消融和结果汇总。研究对象是一个已经训练完成且在检测阶段保持冻结的植物细粒度分类器。研究任务不是提高或改变该分类器的分类结果，而是为其每个 Top-1 预测生成一个错误风险分数，用于识别类内分布（in-distribution, ID）测试图像中的错误分类。

本实验严格限定为：

- 任务：错误分类检测（misclassification detection / failure prediction / selective classification）；
- 场景：4271 类植物细粒度单标签分类；
- 错误定义：冻结分类器的 Top-1 预测类别不等于真实类别；
- 检测器只能判断该 Top-1 预测是否可能错误，不能修改、替换或重新排序原分类结果；
- 本阶段不研究分布外检测、开放集识别、未知类别发现、标签纠错和分类器再训练；
- 所有可训练模块不得使用 `official_val` 进行模型选择、阈值选择或超参数调整。

> **类别数更正：** 当前数据、类别映射和教师检查点均为 **4271 类**，不是早期方案中记录的 4721 类。后续代码、表格和论文统一使用 4271。

## 1. 实验研究目标

### 1.1 总体目标

在不改变冻结植物分类器预测结果的条件下，设计一个面向细粒度局部混淆的错误分类检测器。检测器利用冻结分类器的图像特征、Top-K 候选类别表示及候选间竞争关系，输出原 Top-1 预测为错误的概率：

\[
F(x)\rightarrow \bigl(h(x),z(x),\hat y(x)\bigr),
\qquad
\hat y(x)=\arg\max_i z_i(x),
\]

\[
q_{\mathrm{err}}(x)=P\bigl(\hat y(x)\neq y\mid x,F\bigr).
\]

其中，\(F\) 为全程冻结的教师分类器，\(h\) 为分类头实际接收的 1024 维图像特征，\(z\in\mathbb R^{4271}\) 为 logits，\(q_{\mathrm{err}}\in[0,1]\) 越大表示越可能分类错误。

### 1.2 可检验的子目标

1. 验证 Top-K 候选类别条件匹配是否比只使用 Softmax 概率的 MSP、Margin 和概率形状模型提供额外错误检测信息。
2. 验证“候选间竞争信息”是否比只使用预测类的单个匹配分数更适合植物细粒度错误检测。
3. 验证 pair-level 图像—类别匹配辅助监督能否提升与最终任务直接对齐的 correctness/error 监督。
4. 验证提升是否集中在现有方法最难处理的两类样本：高置信度错误和低置信度正确。
5. 检验检测器是否真正使用图像—类别兼容性，而不是仅记忆类别错误率、类别频次或原分类器概率。

### 1.3 成功标准与停止标准

主模型必须在完全相同的冻结教师预测和相同测试样本上与强基线比较。主要选择指标为 `detector_calibration` 上的 Error AUPRC，最终报告四项指定指标。

方法进入完整多种子实验的最低条件：

- 在 `detector_calibration` 上，主方法的 Error AUPRC 同时优于 Margin、7-D probability-shape MLP 和 direct correctness MLP；
- 提升不能仅来自原始 Margin/MSP 的单调变换；
- 去掉 Top-K 竞争分支后性能应出现可复现下降，否则不能声称竞争建模有效。

最终有效性判据：在固定测试集上，相对最强非本方法基线，Error AUPRC 和 AURC 至少有一项获得配对 bootstrap 95% 置信区间不跨 0 的改善，另一项不得显著恶化。FPR@95TPR 单独波动较大，不作为唯一成功依据。

若主模型不能稳定超过 direct correctness MLP 和 7-D probability-shape MLP，则停止继续堆叠网络规模，转而分析特征互补性或否定 Top-K matching 的增益假设。

## 2. 实验研究问题与技术难点

### 2.1 研究问题

**RQ1：** 冻结分类器已经输出 MSP 和 Margin 后，图像特征与候选类别原型之间是否仍包含可用于区分正确/错误预测的增量信息？

**RQ2：** 独立的预测类匹配分数 \(s_{\hat y}\) 是否足够，还是必须利用预测类与第二竞争类及其他 Top-K 类别的相对差距？

**RQ3：** Top-K hard negatives 是否优于随机负类，且最优 K 是否为 5？

**RQ4：** 以 \(\mathbf 1[i=y]\) 为目标的 pair BCE 是否能够帮助最终的 \(\mathbf 1[\hat y\neq y]\) 错误检测，还是会造成训练目标错位？

**RQ5：** 分类器权重原型、分类训练集均值原型及其组合，哪一种类别表示更适合细粒度匹配？

**RQ6：** 方法对同属、同科不同属、同目不同科和跨目错误是否具有不同效果？其改善是否真正来自细粒度近缘混淆？

### 2.2 技术难点

1. **细粒度混淆强。** 现有分析显示，`detector_train` 的 11,236 个错误中，同属错误占 52.11%，同科不同属占 15.46%；MSP≥0.90 的高置信度错误混淆对中，79.43% 至少同科。此类错误通常在全局外观上高度相似。
2. **正确/错误类别不均衡。** `detector_train` 错误率仅 8.76%，`detector_calibration` 错误率约 8.93%，`official_val` 错误率约 9.33%。训练损失、采样和指标方向必须统一处理。
3. **监督目标错位风险。** 任意候选类别是否为真值，与“教师 Top-1 是否错误”不是完全相同的学习问题，必须用直接错误检测损失作为主监督。
4. **捷径学习风险。** 检测器可能只记住预测类别的先验错误率、训练频次或原分类器概率，而非图像—类别匹配关系。
5. **训练—推理候选不一致。** 训练时把真值强行加入 Top-K 会生成推理阶段不可获得的 pair，主实验不采用该策略；`Top-K+GT` 仅作为消融。
6. **测试集反复使用风险。** `official_val` 已被既有实验评估，不能再视为从未查看的 blind test。今后仍可作为固定 benchmark test，但不能根据其结果选择结构。若研究用于正式投稿，应从未参与开发的数据中另建 blind test。

## 3. 实验数据集与数据预处理方案

### 3.1 数据来源与规模

当前实验数据来自工作区内的 iNaturalist 2021 plants 子集，共 4271 个类别。现有拆分由固定种子 42 和按类别独立的确定性随机打乱生成，四个源训练集拆分互不重叠。

| 数据划分 | 每类数量 | 总图像数 | 唯一用途 |
|---|---:|---:|---|
| `classifier_train` | 每类剩余样本 | 956,507 | 训练冻结分类器、构建训练集均值原型 |
| `classifier_val` | 10 | 42,710 | 选择原分类器检查点；不得训练检测器 |
| `detector_train` | 30 | 128,130 | 训练错误检测器、构造 pair |
| `detector_calibration` | 5 | 21,355 | 选模型、选超参数、early stopping、定阈值 |
| `official_val` | 10 | 42,710 | 固定测试评估；不得反向参与开发 |

必须使用 `MisD/data/class_to_idx.json` 作为唯一类别索引来源。程序启动时检查所有 split 的类别数、类别顺序和检查点输出维度均为 4271，并检查 split 路径无交叉。

### 3.2 已有教师预测统计

| Split | 样本数 | 正确数 | 错误数 | Top-1 accuracy / error rate |
|---|---:|---:|---:|---:|
| `detector_train` | 128,130 | 116,894 | 11,236 | 91.23% / 8.76% |
| `detector_calibration` | 21,355 | 19,446 | 1,909 | 91.07% / 8.93% |
| `official_val` | 42,710 | 38,735 | 3,975 | 90.67% / 9.33% |

训练与评估时错误标签必须由冻结教师的当前在线预测重新定义：

\[
r(x)=\mathbf 1[\arg\max_i z_i(x)\neq y].
\]

缓存 CSV 仅用于加速和一致性检查，不得在教师权重、预处理或类别索引发生变化后继续复用。

### 3.3 图像预处理

为保证教师输出不发生变化，检测实验沿用现有确定性评估预处理：

1. RGB 解码；
2. Resize 短边至 256；
3. Center Crop 为 \(224\times224\)；
4. 转为 tensor；
5. 使用 ImageNet mean/std 标准化。

主实验不对检测器单独增加随机裁剪或颜色增强，因为检测器必须对应教师在固定输入上的真实预测。若后续研究 test-time augmentation，应作为独立方法，不得与主结果混合。

### 3.4 类别原型构建

均值视觉原型只能由 `classifier_train` 构建：

\[
\mu_i=\operatorname{Norm}\left(
\frac{1}{|D_i|}\sum_{x\in D_i}\operatorname{Norm}(h(x))
\right).
\]

不得使用 `detector_train`、`detector_calibration` 或 `official_val` 更新原型。保存原型时必须记录检查点哈希、类别映射哈希、来源 split、每类样本数、特征维度和归一化方式。

### 3.5 数据协议审计

每次正式训练前执行以下 Gate：

- Gate-D1：五个 split 类别索引完全一致；
- Gate-D2：`classifier_train`、`classifier_val`、`detector_train`、`detector_calibration` 文件无交叉；
- Gate-D3：随机抽样比较在线教师与缓存 CSV 的 Top-1、Top-K、MSP 和 Margin，允许的数值误差不超过预先设定容差；
- Gate-D4：确认代码在训练和模型选择阶段未实例化 `official_val` DataLoader；
- Gate-D5：记录各 split 的错误率和 Top-K recall。

## 4. 实验模型与核心方法

### 4.1 冻结教师分类器

教师模型采用现有 `vit_large_patch16`，使用 PlantCLEF2022 MAE 预训练权重，global pooling 输出 1024 维特征；分类头为 `BatchNorm1d(affine=False) + Linear(1024, 4271)`。现有最佳线性探测检查点在 `classifier_val` 上 Top-1 为 91.05%、Top-5 为 98.29%。

检测器训练期间：

- ViT backbone、BatchNorm统计量和线性分类头全部冻结；
- 教师始终处于 `eval()`；
- 教师的 \(z\)、Top-K 和 \(\hat y\) 不参与梯度更新；
- 所有检测方法共享完全相同的 \(\hat y\)，因此分类准确率保持不变。

### 4.2 Top-K 候选生成

\[
\mathcal C_K(x)=\operatorname{TopK}(z(x)),
\qquad \hat y=\mathcal C_K(x)_1.
\]

第一版主实验固定 \(K=5\)。候选完全来自冻结教师，不在主实验中注入真值。记录 `GT-in-TopK` 指示变量仅用于分析，不作为模型输入。

### 4.3 类别表示

主实验分别形成两种冻结类别表示：

- 分类器权重原型 \(w_i\)：使用 BN 在 eval 模式下折叠后的有效分类权重，避免直接使用 raw linear weight 与教师实际决策空间不一致；
- 分类训练集均值原型 \(\mu_i\)：由 `classifier_train` 的 L2 归一化特征均值构建。

主模型使用二者的可学习投影，不学习纯类别 ID embedding：

\[
e_i=\phi_w(\operatorname{Norm}(w_i))+\phi_\mu(\operatorname{Norm}(\mu_i)).
\]

这样可以减少仅记忆类别先验的风险。`weight only`、`mean prototype only` 和 `learnable ID only` 作为消融。

### 4.4 候选匹配模块

对每个 \(i\in\mathcal C_K(x)\)，构造图像—类别交互：

\[
v=\phi_h(\operatorname{LN}(h)),
\]

\[
u_i=[v,e_i,v\odot e_i,|v-e_i|,\cos(v,e_i),\ell_i,\Delta\ell_i,\rho_i],
\]

其中：

- \(\ell_i\) 为候选 logit 或稳定变换后的 log probability；
- \(\Delta\ell_i=z_{\hat y}-z_i\)；
- \(\rho_i\) 为归一化候选排名；
- \(v\odot e_i\) 和 \(|v-e_i|\) 显式表达乘性与距离交互。

共享匹配 MLP 输出 pair logit：

\[
a_i=M(u_i),\qquad s_i=\sigma(a_i).
\]

主模型中所有候选共享同一个 \(M\)，而不是为 4271 类分别建立独立网络。

### 4.5 竞争感知聚合模块

最终错误检测不能只使用 \(s_{\hat y}\)。构造如下候选竞争统计：

\[
g(x)=\left[
a_{\hat y},
a_{\hat y}-\max_{i\neq\hat y}a_i,
\operatorname{LSE}(a_{\mathcal C_K}),
H(\operatorname{softmax}(a_{\mathcal C_K})),
z_{(1)}-z_{(2)},
p_{(1)},
H(p_{\mathcal C_K})
\right].
\]

聚合器输出错误 logit：

\[
b=A(g(x)),\qquad q_{\mathrm{err}}=\sigma(b).
\]

这里 \(H\) 只对归一化分布计算。不得直接把未归一化的独立 Sigmoid 分数当作多类概率计算熵。

### 4.6 损失函数

最终任务的主损失直接监督教师是否错误：

\[
L_{\mathrm{err}}=\operatorname{WBCEWithLogits}
\left(b,\mathbf 1[\hat y\neq y]\right).
\]

候选匹配作为辅助监督：

\[
L_{\mathrm{pair}}=
\frac{1}{K}\sum_{i\in\mathcal C_K}
\operatorname{BCEWithLogits}(a_i,\mathbf 1[i=y]).
\]

总损失：

\[
L=L_{\mathrm{err}}+\lambda L_{\mathrm{pair}}.
\]

主配置使用 \(\lambda=0.25\)，并消融 \(\lambda\in\{0,0.1,0.25,0.5,1.0\}\)。当真值不在 Top-K 时，所有 pair target 为 0；这与推理候选分布一致。

错误类权重在整个 `detector_train` 上预先计算一次，禁止按 batch 动态变化：

\[
w_{\mathrm{err}}=\frac{N_{\mathrm{correct}}}{N_{\mathrm{error}}}
=\frac{116894}{11236}\approx10.40.
\]

主实验使用标准 `pos_weight=10.40`；现有代码中的 \(\log(1+N_c/N_e)\) 作为消融，因为它约为 2.43，与标准逆频率权重不是同一个定义。模型选择仍基于阈值无关的 Error AUPRC，避免把加权 BCE 数值当作最终性能。

### 4.7 推理规则

推理阶段保持：

\[
\text{predicted class}=\hat y=\arg\max_i z_i.
\]

检测器只输出：

\[
q_{\mathrm{err}}\ge\tau\Rightarrow\text{reject / likely error},
\]

\[
q_{\mathrm{err}}<\tau\Rightarrow\text{accept / likely correct}.
\]

禁止使用 \(\arg\max_i s_i\) 改写预测类别。阈值 \(\tau\) 只能在 `detector_calibration` 上根据预先声明的工作点选择。

## 6. 实验评价指标说明

统一定义错误为正类：

\[
y_{\mathrm{err}}=\mathbf 1[\hat y\neq y],
\]

所有提交给指标函数的分数均满足“越大越可能错误”。对于 MSP、Margin 等正确置信度，应先取负值或 \(1-\text{confidence}\)。

### 6.1 AUROC ↑

衡量随机抽取一个错误样本与一个正确样本时，错误样本获得更高错误分数的概率。与单一阈值无关，但在错误比例较低时可能显得乐观。

### 6.2 Error AUPRC ↑

以错误预测为正类计算 Precision–Recall 曲线下面积。它直接反映错误样本少数类场景下的检测质量，是模型选择的主指标。报告时必须同时给出随机基线，即测试错误率；`official_val` 的随机 Error AUPRC 基线约为 0.0933。

### 6.3 FPR@95TPR ↓

先在同一评估集合的完整阈值曲线上找到错误召回率 TPR 达到至少 95% 的阈值，再报告正确预测被误报为错误的比例：

\[
\mathrm{FPR}=P(q_{\mathrm{err}}\ge\tau\mid \hat y=y).
\]

若存在多个满足 TPR≥95%的阈值，使用其中 FPR 最小者，并固定插值/离散实现。该指标用于方法比较，不等同于从 calibration 迁移到 test 的部署阈值结果；后者应额外报告实际 test TPR/FPR。

### 6.4 AURC ↓

按“正确置信度”从高到低接受样本，计算不同 coverage 下被接受样本的分类风险，并对 Risk–Coverage 曲线积分。错误分数需转换为：

\[
c_{\mathrm{correct}}=1-q_{\mathrm{err}}.
\]

由于所有方法固定同一个教师及其错误率，AURC可公平比较。实现中必须规定 tie-breaking，并以全部样本排序后的离散积分为唯一实现。

### 6.5 统计报告

最终表格报告三种子均值±标准差；另对最佳方法与最强基线进行 2000 次 paired bootstrap，报告四项指标差值的95%置信区间和胜率。bootstrap必须以样本为单位并在所有方法间复用同一重采样索引。

辅助分析报告：Risk@Coverage（80%、90%、95%）、高置信度错误召回率、低置信度正确误拒率，以及按分类学关系分组的 Error AUPRC/AUROC。辅助指标不得替代四项主指标。

## 7. 详细实验步骤与技术路线

### 阶段 A：协议冻结与教师复现

1. 固定类别映射、五个数据 split、教师检查点和预处理。
2. 运行数据交叉检查和在线/缓存教师一致性检查。
3. 在三个检测 split 上重新统计样本数、错误数、Top-1、Top-5和错误率。
4. 验证教师在任何检测器训练前后 logits 和 Top-1 完全一致。
5. 输出 `protocol_manifest.json`，包含所有路径、哈希、环境和统计。

**通过条件：** 类别索引、教师预测和数据划分全部一致；否则禁止继续训练。

### 阶段 B：统一重算强基线

使用同一指标实现、同一 `official_val` 预测重新计算：

1. MSP；
2. Margin；
3. Entropy；
4. Max Logit；
5. Energy；
6. 7-D probability-shape MLP；
7. direct correctness MLP：输入 \([h,z_{TopK},p_{TopK},\hat y]\) 的受控低维表示；
8. class-prior-only：只输入 \(\hat y\) 及该类在 `detector_train` 的平滑错误率；
9. probability-only：只输入 Top-K 概率/间隔，不输入图像和类别原型。

现有历史结果仅作为复现参照，不直接拼接进新表：

| 历史方法 | AUROC | Error AUPRC | FPR@95TPR | AURC |
|---|---:|---:|---:|---:|
| MSP | 0.9043 | 0.5050 | 0.3732 | 0.01526 |
| Margin | 0.9092 | 0.5139 | 0.3640 | 0.01468 |
| 7-D probability-shape MLP | 0.9128 | 0.5453 | 0.3567 | 0.01413 |
| mean-prototype bottleneck K=5 | 0.7864 | 0.3004 | 0.6946 | 0.03309 |
| competition_v2 K=5 | 0.8865 | 0.4589 | 0.4374 | 0.01816 |

这些结果表明：单纯原型匹配明显不足，竞争统计虽有较大改善，但尚未超过强概率基线。任务书中的正式方法必须证明新增 pair监督、直接错误监督和相对竞争聚合确实提供增量信息。

> 既有 fusion audit 的 Margin=0.9200 是在 `detector_calibration` 上进行的开发性 OOF 审计，不是 `official_val` 结果，禁止与上表测试结果直接比较。

### 阶段 C：构建冻结类别原型

1. 从教师分类头提取 BN-effective classifier weights；
2. 仅用 `classifier_train` 构建 mean prototypes；
3. 校验原型形状为 `[4271, 1024]`；
4. 保存原型元数据与哈希；
5. 分析 \(w_i\) 与 \(\mu_i\) 的余弦相似度及其和类别频次的关系。

### 阶段 D：最小可行实验（seed 0）

依次训练：

| ID | 模型 | 目的 |
|---|---|---|
| E0 | direct correctness MLP | 最强直接任务对照 |
| E1 | Top-1 matching + \(L_{err}\) | 类别条件匹配是否有用 |
| E2 | Top-5 matching，仅 \(s_{\hat y}\) | 增加候选但不聚合竞争 |
| E3 | Top-5 competition aggregator，仅 \(L_{err}\) | 竞争信息贡献 |
| E4 | Top-5 competition + \(L_{err}+0.25L_{pair}\) | 正式主方法 |

所有模型只根据 `detector_calibration` Error AUPRC保存最佳epoch。此阶段不读取 `official_val`。

**进入下一阶段条件：** E4优于E0及7-D MLP在相同 calibration 协议下的结果，且E4优于E2；否则先做错误分析，不跑大规模消融。

### 阶段 E：核心消融

1. **K值：** \(K\in\{1,2,5,10,20\}\)；
2. **负类来源：** Top-K hard negatives、随机负类、同属负类、Top-K+GT；
3. **损失：** \(L_{err}\) only、\(L_{pair}\) only、联合损失；
4. **\(\lambda\)：** 0、0.1、0.25、0.5、1.0；
5. **类别表示：** weight only、mean only、weight+mean、learnable ID only；
6. **竞争统计：** \(s_{\hat y}\)、pair margin、候选熵、全部统计、去除原始logit统计；
7. **类别条件性：** 正确类别原型、随机置换原型、零原型；
8. **错误加权：** 无权重、标准 inverse-frequency、现有 log-compressed 权重；
9. **捷径基线：** class prior only、probability only；
10. **容量匹配：** 让 direct MLP 与主模型参数量大致相当，排除容量增益。

消融只使用 seed 0 和 `detector_calibration`。根据预注册规则固定最终结构后，才进行多种子和测试。

### 阶段 F：多种子正式训练

1. 固定结构、损失、K和全部超参数；
2. 使用 seed 0、1、2 分别训练；
3. 每个seed只保存由 calibration Error AUPRC选出的一个检查点；
4. 保存 calibration 全量预测、训练历史和配置；
5. 检查三种子是否出现方向相反或明显退化。

### 阶段 G：阈值选择

在 `detector_calibration` 上预先选择两类工作点：

- 错误召回优先：选择达到 TPR-error≥95% 且 FPR最小的阈值；
- 风险约束优先：选择被接受样本风险不超过预设值（如5%）时 coverage 最大的阈值。

保存阈值后锁定，迁移到测试集时不得重新调整。阈值部署结果与测试集上扫描得到的FPR@95TPR必须分开报告。

### 阶段 H：固定测试评估

1. 在全部方法和种子完全锁定后运行 `official_val`；
2. 每张图保存 `sample_id,true_label,pred_label,error_label,error_score,MSP,Margin,TopK`；
3. 计算 AUROC、Error AUPRC、FPR@95TPR、AURC；
4. 汇总三种子均值±标准差；
5. 对最佳方法与最强基线进行 paired bootstrap；
6. 不允许根据测试结果回到阶段E修改模型；如修改，必须将其标为新一轮开发并承认 test reuse。

### 阶段 I：细粒度错误分析

按照已有分类学字符串将错误划分为：

- 同属；
- 同科不同属；
- 同目不同科；
- 跨目。

重点比较主方法相对 Margin 在以下集合上的变化：

- MSP≥0.90的高置信度错误；
- MSP≤0.50的低置信度正确；
- 真值在Top-5内与不在Top-5内；
- 同属/同科错误与跨目错误；
- 预测类别高/中/低错误率组；
- 类别训练样本数分组。

人工案例只用于解释最终结果，不用于再次修改模型。展示成功检出、仍漏检和新增误拒绝三类案例，避免只展示正面样本。

## 8. 预期实验结果与实验结论

以下是待验证假设，不是预先保证的结果。

### 8.1 预期结果

1. Margin和7-D probability-shape MLP仍将是非常强的基线；只使用原型或patch特征的检测器可能无法超过它们。
2. 只使用 \(s_{\hat y}\) 的独立匹配模型提升有限，因为它忽略最相似竞争类别。
3. 竞争聚合器预计主要改善高置信度近缘类别错误的排序，从而提高 Error AUPRC、降低AURC。
4. Pair辅助监督只有在与 \(L_{err}\) 联合使用时才可能稳定有效；单独pair BCE可能因目标错位而较弱。
5. Top-K hard negatives预计优于随机负类；K从1增至5应改善，继续增大后收益可能饱和或下降。
6. `weight+mean prototype` 预计比任一单一原型更稳定，但必须由实验确认。
7. FPR@95TPR可能不会与AUROC/AUPRC同步改善，因此必须同时看四项指标和置信区间。

### 8.2 允许形成的结论

若主方法显著超过所有强基线且消融支持各模块，可得出：

> 在固定植物细粒度分类器上，Top-K局部混淆集合中的类别条件兼容性和候选间相对竞争关系，包含超越Softmax概率形状的错误检测信息；直接错误监督与pair辅助监督的联合优化可改善固定Top-1预测的failure ranking。

若主方法仅在与Margin融合后提升，可得出：

> 匹配特征本身不足以替代概率置信度，但与分类器Margin具有互补性。

若主方法不能超过direct correctness MLP或概率基线，应如实得出：

> 当前冻结特征和类别原型下，Top-K匹配没有提供足够的增量错误信息；主要检测能力仍来自教师概率形状，不能宣称多个二分类或匹配机制有效。

## 9. 实验可能遇到的问题及处理方案

| 问题 | 诊断信号 | 处理方案 |
|---|---|---|
| 类别数写错 | checkpoint/data维度不一致 | 全项目统一4271并在启动时assert |
| 教师预测漂移 | 在线预测与缓存CSV不一致 | 固定预处理、eval模式、BN统计和软件版本；缓存作废重导 |
| 检测器训练过拟合 | train持续提高、calibration早期下降 | bottleneck、dropout、weight decay、early stopping；不增加模型容量 |
| 错误样本少 | loss被正确样本支配、错误召回低 | 固定全局pos_weight；比较加权策略；主选择看Error AUPRC |
| batch内无错误 | 动态pos_weight异常 | 禁止按batch估权；使用训练集固定权重 |
| 只记忆类别先验 | class-prior-only接近主模型 | 平滑先验baseline、原型置换、按类别分组评估 |
| 只复制MSP/Margin | 去掉图像/原型后性能不降 | 做probability-only、zero/shuffled prototype消融 |
| Pair目标错位 | pair loss下降但Error AUPRC不升 | 降低\(\lambda\)或移除pair loss，以\(L_{err}\)为主 |
| Top-K+GT分布泄漏 | 训练改善、测试无改善 | 主实验仅Top-K；Top-K+GT只做消融 |
| 原型质量受长尾影响 | 低频类明显退化 | 报告频次分组；比较classifier weights与均值原型 |
| K增大显存不足 | OOM | 缓存冻结特征/原型、分块候选计算、梯度累积；不降低教师输入分辨率 |
| AMP数值异常 | entropy/log/softmax出现NaN | logits和指标转float32；log输入加epsilon；稳定LSE |
| FPR@95TPR实现不一致 | 不同脚本结果不同 | 建立唯一metrics模块和单元测试，固定正类与分数方向 |
| AURC方向错误 | 错误分数越高反而越早接受 | 使用 \(1-q_{err}\) 作为接受置信度并做合成数据测试 |
| official test过度使用 | 根据测试结果持续改结构 | 测试结果只做报告；投稿前另建blind test |
| 多种子结论不稳定 | 均值提升但方差很大 | 增加种子、paired bootstrap，不宣称稳定提升 |
| 高置信度错误疑似错标 | 人工案例无法判断 | 单独标记疑似错标/多主体；主指标仍按现有标签，另做敏感性分析 |

## 11. 最终技术路线摘要

```text
输入植物图像 x
    ↓
冻结 ViT-L/16 教师 F
    ├── 固定 Top-1 预测 ŷ（最终类别，绝不修改）
    ├── 1024-D 图像特征 h
    └── 4271-D logits z → Top-K 候选
                         ↓
             候选类别权重/均值原型
                         ↓
       K 个共享 Image–Class Matching 分数 a_i
                         ↓
  预测类分数 + pair margin + 候选熵 + logit margin
                         ↓
              Competition Aggregator
                         ↓
        q_err = P(教师 Top-1 预测错误)
                         ↓
 calibration 选阈值 → accept / reject
```

训练以教师Top-1错误标签为主监督，以候选pair真值匹配为辅助监督；开发只使用 `detector_train` 和 `detector_calibration`，固定后再在测试集报告 AUROC、Error AUPRC、FPR@95TPR 和 AURC。
