# Misclassification dataset splits

Generated by `MisD/build_dataset_splits.py`. Images are hard links to the source by default, so deleting this output does not delete source images.

- `classifier_train`: remaining source-train images after held-out allocations
- `classifier_val`: 10 source-train images per class
- `detector_train`: 30 source-train images per class
- `detector_calibration`: 5 source-train images per class
- `official_val`: complete official source val, reserved as final detector test
