# 新版 detector_train 错图总结

## 数据协议

本次探索只分析分类器未用于自身训练的 `detector_train.csv`：128,130 张图片，
其中预测正确 116,894 张、错误 11,236 张，Top-1 accuracy 为 91.23%。

- `classifier_train` 只用于训练分类器，不适合统计泛化错误；
- `detector_train` 用于错图探索与错误检测器训练；
- `detector_calibration` 用于选择阈值和校准；
- `official_val` 保留到方法完全固定后进行一次最终评估。

本次人工查看会影响研究方向，因此页面中的结果是开发证据，不应作为最终测试结论。

## 六组人工审查样本

固定随机种子为 42，随机四组各抽 50 张：

| 分组 | 候选池 | 抽样数 | 规则 |
|---|---:|---:|---|
| 高置信度错误 | 685 | 50 | error=1, MSP >= 0.90 |
| 高置信度正确 | 80,022 | 50 | error=0, MSP >= 0.90 |
| 低置信度错误 | 6,273 | 50 | error=1, MSP <= 0.50 |
| 低置信度正确 | 6,640 | 50 | error=0, MSP <= 0.50 |
| 最高置信度错误 | 11,236 | 50 | 按 MSP 降序前 50 |
| 最低置信度正确 | 116,894 | 50 | 按 MSP 升序前 50 |

随机四组用于估计各类现象，两个极端组用于观察 MSP 最典型的漏检和误拒绝案例。

## 高置信度混淆对

三个阈值采用累计集合：

| MSP 阈值 | 错误图片 | 混淆类别对 | 同属类别对 | 同科不同属 |
|---|---:|---:|---:|---:|
| >= 0.90 | 685 | 632 | 389 | 113 |
| >= 0.95 | 341 | 333 | 197 | 68 |
| >= 0.99 | 61 | 59 | 29 | 16 |

`MSP >= 0.90` 的混淆对中，502/632（79.43%）至少属于同科，说明高置信度错误明显集中在近缘类别。
每个类别对的审查页面包含全部对应错图，以及真实类别、预测类别各 3 张正确预测参考图。

## 整体错误结构

11,236 个错误按分类学关系分布如下：

| 分类学关系 | 数量 | 比例 |
|---|---:|---:|
| 同属 | 5,855 | 52.11% |
| 同科不同属 | 1,737 | 15.46% |
| 同目不同科 | 558 | 4.97% |
| 跨目 | 3,086 | 27.47% |

这支持两个并行审核方向：

1. 同属/同科高置信度错误：检查真实的细粒度视觉相似、关键器官缺失和生长阶段差异；
2. 跨目高置信度错误：优先检查错标、多主体、背景捷径、主体过小和异常图片。

## 研究重点

MSP 和 Margin 都由同一组分类 logits 导出，模型坚定地选错时二者会同时失效。当前最值得解决的两类样本是：

1. 高置信度错误：MSP 无法发现的漏检，重点研究近缘类别、缺少关键部位、标签歧义和背景捷径；
2. 低置信度正确：MSP 会错误拒绝的困难正确样本，重点研究如何降低 FPR，同时保留真正困难但可识别的图片。

人工标注时建议至少记录：细粒度相似、关键部位缺失、主体过小、模糊、遮挡、多植物、背景干扰、
非典型生长阶段、器官差异、疑似错标、明显跨类误判、无法判断。标签允许多选。
